# Hydra Fit

Hydra Fit is a health and wellness dashboard designed to help users track their daily hydration, habits, and calories burned through activities.

##  Live Preview

[View Hydra Fit Live](https://shahreena133.github.io/Hydra-Fit/)

##  Features

-  Daily hydration tracking
-  Habit streak tracking
-  Add new habits
-  Log habits for today
-  Delete habits
-  Active calorie calculator
-  Dark Mode and Light Mode
-  Data persistence using LocalStorage
-  Responsive layout

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages

##  Project Files

- `index.html` — Structure of the Hydra Fit dashboard
- `style.css` — Styling, themes, cards, buttons, and responsive layout
- `script.js` — Hydration, habits, calories, theme switching, and LocalStorage functionality
